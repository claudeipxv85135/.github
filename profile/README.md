<p>“先试用再付款”在住宅 IP 这一行几乎是标配，但试用装和正式装的区别往往不在速度，而在出口的复用历史、替换规则和故障响应。不少人试三天觉得延迟还行就下单，正式跑起来才发现出口是共享池、换 IP 要另外计费、出问题只能排队等工单。这篇用对照实验的思路，把试用期该验证的三件事——延迟、纯净度、替换政策——拆成三天内能跑完的动作，每一步给出命令、观察窗口和判读标准。</p>

<h2>一、把“试用”拆成三件可验证的事</h2>
<p>试用不是体验手感，是拿有限的时间换一份可对比的数据。先把要验收的指标写下来再去申请，顺序反了很容易被销售话术带着走。</p>
<h3>指标先定，额度后谈</h3>
<p>至少写清四项：峰值时段的中位延迟、丢包率、出口 ASN 是否属于住宅运营商、单 IP 允许的并发连接数。前两项决定能不能干活，后两项决定账号环境像不像真实家庭网络。测试额度通常给 1–3 个出口、1–7 天，具体以服务商当期说明为准。</p>
<h3>观察窗口要覆盖你的工作时段</h3>
<p>跨境电商和内容团队的活跃时间多在对方国家的白天，也就是国内的后半夜。如果只在下午三点测半小时，拿到的数字几乎没有参考价值。建议至少覆盖当地 09:00–12:00 与 19:00–23:00 两个窗口，各测一轮。</p>

<h2>二、对照实验：同账号、同时段，只换出口</h2>
<p>单组数据没有意义，必须有基线。最省事的做法是把机房出口当 A 组、住宅出口当 B 组，其余变量全部锁死。</p>
<h3>A 组：机房出口做基线</h3>
<p>用同一条命令、同一个目标域名、同一台机器跑，记录中位值与 P95。机房出口的握手延迟通常更低，但首字节之后的交互表现不一定更好，这正是需要对比的地方。</p>
<h3>B 组：住宅出口做对照</h3>
<p>把代理指向试用出口，命令保持一致，只改代理参数。curl 可以这样打十次取分布：<code>for i in $(seq 10); do curl -o /dev/null -s -w "%{time_connect} %{time_starttransfer} %{time_total}\n" -x http://user:pass@host:port https://example.com; done</code>，把输出贴进表格算中位数，比看单次结果靠谱得多。</p>
<h3>两组之间留出间隔</h3>
<p>切换前后间隔 5–10 分钟，避免目标站点侧的限流窗口重叠，让 B 组替 A 组背锅。这个细节看起来吹毛求疵，但在排查“为什么住宅出口更慢”时经常是主因。</p>

<h2>三、延迟和抖动怎么测才有可比性</h2>
<p>延迟不是单一数字，中位数、P95、抖动三者要一起看。做过跨境的人都遇到过年“平均 180ms 但每分钟卡一次”的线路，问题就藏在长尾里。</p>

<h2>四、纯净度自查的三个入口</h2>
<p>纯净度这个词被用得很泛，落到可操作层面其实就是三件事：地址归属、历史滥用记录、同出口的邻居数量。</p>
<h3>归属与 ASN</h3>
<p>查 ipinfo.io 或 ipapi.is，看 ASN 的 type 字段是不是 isp，org 是不是当地宽带运营商。显示 hosting 或 business 的，说明这条出口更接近机房段，和“住宅”的预期对不上。</p>
<h3>历史与邻居</h3>
<p>用公开的黑名单查询入口过一遍，再看反向解析是否指向运营商域名。邻居数量供应商一般不会主动说，可以直接问“这个 /24 里目前有多少客户在用”，回答含糊的基本就是共享池。</p>

<h2>五、替换政策里最容易漏掉的条款</h2>
<p>试用期最该问清的不是“能不能换”，而是“多久能换一次、换了算不算钱、换完原来的还留不留”。</p>
<h3>四个必问项</h3>
<p>替换频率（每天几次）、冷却期（换完多久才能再换）、计费口径（是否消耗额度）、旧出口的回收时间，四项都要落到文字。有的服务商换 IP 免费但限每天一次，遇到连续异常的场景根本不够用；有的按次收费，单价看着低，月度总账可能翻倍。</p>
<h3>把口头承诺写进工单</h3>
<p>试用期所有承诺都用文字留痕，工单里回一句“确认：每月可免费替换 3 次，超出按 X 元/次计”，后面扯皮时这就是依据。这一步花的时间，远比事后反复沟通便宜。</p>

<h2>常见问答</h2>
<h3>试用期一般给几天？</h3>
<p>答：常见 1–7 天，也有按流量给额度的（如 1–5GB）。时间太短跑不完两个时段，建议优先选能给到 3 天以上的，具体以服务商当前政策为准。</p>
<h3>试用出口和正式出口是同一批吗？</h3>
<p>答：不一定。部分服务商试用走公共池、正式走独享池，体验会更好；也有反过来的情况——试用给的是空闲出口，上线后被塞进高密度池。下单前把归属问清楚。</p>
<h3>延迟达标就说明能用吗？</h3>
<p>答：不够。延迟只反映链路质量，还要看 ASN 类型、黑名单命中和邻居密度。三项里有一项不合格，延迟再低也可能在登录环节出问题。</p>
<h3>试用不满意能退吗？</h3>
<p>答：看合同。多数按月付的产品在首次开通后 3–7 天内可申请退款，年付通常不支持。把退款条款截图存档，比事后争论有效。</p>
